### 2.1 使うログ

`..\e1c_<v>mms_<形>_<L|R>_000N.csv`．6 つの条件で，左右それぞれ数本ある．

| パネルの題（この文字だけを書く） | ファイル名の `<v>mms_<形>` |
|---|---|
| 小回り 0.3 m/s | `300mms_s90` |
| 小回り 0.5 m/s | `500mms_s90` |
| 小回り 0.6 m/s | `600mms_s90` |
| 小回り 0.7 m/s | `700mms_s90` |
| 大回り 90° 0.6 m/s | `600mms_l90` |
| 大回り 180° 0.5 m/s | `500mms_l180` |

- 1 kHz．列の例：`time_s, step, seg, v_cmd, pwm_l, pwm_r, vbat, vl, vr, gyro_z, …, angle, v_ref, v_ff, v_p, v_i, v_d, v_d0, dv, v_d_meas, omega_ref, omega_dot_ref, theta_ref, F_ff, v_d_ff, v_s_ff`
- **単位は先に確かめる**（`gyro_z` と `omega_ref` が dps か rad/s か，`vl`/`vr` が m/s か mm/s か）．最初に 1 本読んで，列ごとの最小・最大を出して判断すること．目安：小回り 0.5 m/s の目標の最大の角速度は 450 deg/s，速さは 0.5 m/s
- `seg`：1 加速，2 直進 0.2 s，**3 ターン（旋回は FF だけ，並進は PI あり）**，4 直進 0.1 s，5 停止，9 中止
- ターン中は `v_d_meas` の記録に不具合があるので使わない．$V_d$ は pwm と vbat から作る：
  - $V_L = \mathrm{pwm\_l}/4199 \times \mathrm{vbat}$，$V_R = \mathrm{pwm\_r}/4199 \times \mathrm{vbat}$，$V_d = (V_R - V_L)/2$
  - pwm の符号の向き（後転が負か）を確かめること．直進の区間で $V_d$ が −0.1 V 前後になれば合っている
- $D$：その本の `v_d0` の値（区間 2 の最後 0.1 s の $V_d$ の平均）．列がなければ，区間 2 の最後 0.1 s の $V_d$ を平均する

### 2.2 モデル（1 ms ごと．係数は記事の最終の値）

区間 3 の最初の行から，区間 3 の最後の行まで計算する．

```
b_w = 9.20e-3;  sigma = 3.02e-3;  A_plus = 0.32;  A_minus = 0.216;
kappa0(v) = interp1([0.3 0.5 0.75 1.0 1.5], [1.03 1.14 0.80 0.89 0.92], v)   % 範囲の外は端の値
h(kappa, v) = A * asinh(kappa / kappa0(v))     % A は kappa >= 0 なら A_plus，負なら A_minus

v_k  = (vl + vr)/2 の実測（m/s）
omega_0 = その時の実測，F_0 = h(omega_0/v_0, v_0)
omega_{k+1} = omega_k + dt/b_w * (V_d(k-1) - D - F_k)          % 入力の遅れ 1 ms
F_{k+1}     = F_k + min(v_k*dt/sigma, 1) * (h(omega_k/v_k, v_k) - F_k)
```

- 角速度は rad/s で計算し，図は deg/s で描く
- 右回り（`_R_`）は，ω の符号を反対にして「回る向きを正」にそろえる（実測・モデル・目標とも）

### 2.3 そろえ方と平均

- 時間の 0 を区間 3 の最初の行にそろえる
- 条件ごと・左右ごとに，実測，モデル，目標（`omega_ref`）を平均する（短い本に合わせて切る）
- 中止（seg 9）の本も，区間 3 の分は使ってよい

### 2.4 図の形

- 2 行 × 6 列．上の行：角速度 [deg/s]，下の行：実測 − モデル [deg/s]．列の順は 2.1 の表の順
- 色：左回り = 青 `[0.165 0.435 0.859]`，右回り = 橙 `[0.851 0.510 0.169]`
- 線：実測 = 実線，モデル = 破線，目標 = 灰色の点線
- 角加速の区間（目標の ω が増えている間）を薄い青，角減速の区間を薄い橙で塗る
- パネルの題は 2.1 の表の文字だけ．図全体の題は付けない
- 凡例は左上のパネルに 1 つ：「左回り 実測」「左回り モデル」「右回り 実測」「右回り モデル」「目標」．本数は書かない
- 横軸：ターン開始からの時間 [ms]．縦軸の題：上「ω（回る向きを正）[deg/s]」，下「実測 − モデル [deg/s]」
- 大きさ：横 2200 × 縦 780 px くらい（`exportgraphics(..., 'Resolution', 200)` など）．背景は白

### 2.5 確かめ

一定の区間（目標の ω が一定の間）の平均で「実測 / モデル」を出して，表にして報告してください．前の解析では，右回りが 0.94〜1.04 でした．左回りは $A_+$ を 0.32 にしたので，前より 1 に近づくはずです（前は $A_+$ = 0.296 で 0.61〜1.08）．大きく違えば，単位か符号を疑ってください．
