# yuho の寸法(機体の外形・旋回中心・車輪・壁センサ・迷路)

plant_sim(ぶつかるシミュレーション)を作るときにユーザーから受け取った寸法を，1か所にまとめたもの(2026-11-04)．
元の記録は plant_sim の worktree `M:\User\Desktop\school\club\sim`(ブランチ `feature/plant-model-fit`)にある(最後の「出どころ」を参照)．

## 1. 機体の座標

- 原点: **4輪の接地点の真ん中**(前後の車軸の真ん中で，かつ左右の真ん中)．
- x は前，y は左が正 [mm]．角度は真っ直ぐ前が 0°，反時計回り(左)が正 [deg]．
- 原点をここにした理由: モーターの軸の位置は機体の動き方に効かず，効くのは車輪が床に触れる位置．
  前後対称の4輪なら，超信地旋回の回転の中心はおおよそ4輪の真ん中になるので，式が簡単になる．

## 2. 旋回中心

- **測った値ではない**．「前後対称の4輪なので，旋回の中心 ＝ 原点(4輪の真ん中)」と仮定している．
- plant_sim で壁センサを実機のログに合わせたとき，置いた位置のずれがいくつかの区画で同じ向き(−10〜−15mm 西，+6〜+11mm 北)にそろった．
  その原因の候補の一つに「回る中心が原点と違う」が挙がっていて，確かめていない(plant_sim の設計記録 838 行，849 行あたり)．
- スラロームでは横滑り(スリップアングル β)があるので，回る中心は速さ・曲がり方で動く．機体の座標で決まった1点ではない．

## 3. 駆動と車輪

- 左右それぞれ1つのモーターで，前後2つの車輪を回す．前後はギアでつながる．前輪と後輪は同じ大きさで前後対称．

| ホイールベース(前の車軸と後ろの車軸の間) | 26.7 | — |
| トレッド(左右の車輪の接地点の間) | 54.910 | `TREAD_WIDTH_MM` 64.75(実効の値) |
| タイヤの直径 | 23.5 | `WHEEL_DIAMETER_MM` 23.81 |

- ファームのトレッドは設計の値より約 10mm 大きい．4輪の横のこすりを含めた実効の値．
- ギア: ピニオン 13，スパー 42(M0.5)．

## 4. 機体の外形

上から見て，基板とタイヤのうち外側にあるほう．形は `base_plate.DXF`(メイン基板)から取った．

| 項目 | 値 [mm] |
|---|---|
| 一番前の x | +62.34(ユーザーの値は 62.33) |
| 一番後ろの x | −37.66(ユーザーの値は −37.67) |
| 一番左の y | +35.0 |
| 一番右の y | −35.0 |
| 全長 × 幅 | 100.0 × 70.0 |

- ユーザーの値と DXF から求めた値は 0.01mm で合う．DXF の y = −36.941(車輪の切り欠き(長さ 47mm)の真ん中，4つの穴の真ん中)を原点にした．
- 前の2つの角を落としている．右前の角は次の3つをつないだ形(左前はこれを y で鏡に写したもの)．
  1. 半径 15mm の円弧: 中心 (41.99, −20.0)．(41.99, −35.0) から (52.60, −30.61) まで．
  2. 45° の直線: (52.60, −30.61) から (57.95, −25.26) まで．
  3. 半径 15mm の円弧: 中心 (47.34, −14.65)．(57.95, −25.26) から (62.34, −14.65) まで．
- 前の辺は x = 62.34，y = −14.65〜+14.65．
- plant_sim では，円弧を3つの線分で近似した凸の多角形(反時計回り)にしている(`tools/plant_sim/world.c` の `BuildOutline`)．
  1ms ごとに機体を進めた後，分離軸の定理で壁・柱との重なりを調べ，重なっていれば一番短い向きに押し戻す．

## 5. 壁センサ

受光部の位置と光軸の向き(光が飛んでいく向き)．発光部は受光部と上下に重ねて付いているので，x，y は受光部と同じ．

| センサ | x [mm] | y [mm] | 光軸の向き [deg] |
|---|---|---|---|
| L | 56.16 | −15.29 | +60 |
| FL | 38.59 | +30.17 | +7 |
| FR | 38.59 | −30.17 | −7 |
| R | 56.16 | +15.29 | −60 |

- 横のセンサは交差している(L は右側に付いていて左を向く，R はその逆)．
- DXF でも確かめた(横のセンサの四角の真ん中が (56.18, ±15.27) で，0.02mm で合う)．
- 高さ: 基板の上面から受光部 10.85mm，発光部 4.15mm．基板の上面は床から 3.7mm(設計)．
  床からは受光部 14.55mm，発光部 7.85mm．
- 部品: 発光部 SFH-4550，受光部 ST-1KL3．

## 6. 迷路

| 項目 | 値 [mm] |
|---|---|
| 区画 | 180(`SECTION_MM`) |
| 壁の厚さ | 12 |
| 壁の高さ | 50 |
| 柱 | 12 × 12 |

- plant_sim の迷路の座標: 原点はスタートの区画の南西の柱の中心．x 東，y 北．
  区画 (cx, cy) の真ん中は (cx × 180 + 90, cy × 180 + 90)．向きは東から反時計回り(北が 90°)．
