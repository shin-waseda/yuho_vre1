### 2026-10-27 同定の実験(E0/E1/E2)のモードを作った(`feature/system-identification`)

- **10-27 の実験計画書(E0 動き出し，E1 並進のステップ，E2 超信地旋回のステップ)を実機で行うため，同定のブランチのファームを同定専用に作り直した**(ユーザーの依頼．
  「同定用のブランチなら何をいじってもよい．今の params.h・モード・走行の関数を消して同定用の走行関数を作って」)．
  - 消したもの: `logic/` すべて(迷路，PID，プロファイル，壁制御，スラローム，odometry/kinematics)，app の走行・試験のモード(control_loop，search_run，
    straight/pivot/slalom_test など)，`interface/flash`．params.h は経験則の調整値(車輪径 23.81，トレッド 64.75，FF・PID)を捨てて作り直し，
    車輪径はノギスの実測 23.35mm にした(速度・距離の換算は比例なので，後で変えても解析で直せる)．
  - 新しく作ったもの:
    - `logic/sysid/step_test`: 区間の状態機械(ハードに触らない)．区間 0 始まり(0V 50ms) → 1 +V(T_acc) → 2 −V(速度か角速度が 0 を切るまで) → 3 ブレーキ(0V 100ms)，
      中止は 9．E0 は区間1で 0.1V/s で上げ，左右の車輪が 0.5mm 動いたときの電圧を覚える(両方動いたら区間3，1.0V で打ち切り)．
      中止: 並進は距離 1000mm，旋回は 1900dps，区間2が 1 秒で止まらないとき．
    - `app/sysid_loop`: control_loop の代わりの 1kHz の処理．開ループで duty = 電圧 / 電池の電圧(フィルタ後)，PWM は四捨五入し，上限で止めた tick を数える．
      走り始めの tick で距離・積分角を 0 にし，記録(Logger_Start)も同じ tick から始める．0V は `Motor_Drive(0,0)`(TB6612FNG ではショートブレーキのはず．未確認)．
    - `app/sysid_mode`: 条件を1回だけ選び(E1/E2: 電圧 FROM・TO，T_acc，回数．E0: 並進か旋回か，回数)，あとは「置いて手かざし → 1本 → 置き直す」で
      次の条件へ進む．並びは電圧ごとに「前進 → 後退」(E2 は「左回り → 右回り」)を回数ぶん．クリックで1本前に戻る．進み具合は LED1〜7 に2進数で出す．
  - ログ: 1本ごとに SD の `sysid/<条件>_NNNN.bin`(例 `e1_fwd_300mv`，`e2_ccw_500mv`，`e0t_fwd`)へ 1kHz で流す．列は time_s，seg，v_cmd，pwm_l，pwm_r，vbat，
    vl，vr，gyro_z，dist，angle の 11 列．区間の列は `ev` ではなく `seg` にした(get_log.py が `ev` 列をイベントの番号として読むため)．
    旋回の v_cmd は正 = 反時計回り(右に +，左に −)．流すブロックを 24KB → 32KB(1kHz・11 列で約 0.74 秒ぶん)，先に確保する大きさを 32MB → 4MB にした．
  - フェイルセーフ: 角速度は 1500 → 1950dps(E2 の 0.5V は理論で約 1820dps)．速度偏差の監視は消した(目標速度がないため)．低電圧はそのまま．
  - モードの選択は一段: 1 E0，2 E1，3 E2，4 SD_DUMP，5 SD_DUMP_ALL．
  - このブランチでは `tools/maze_sim` が `Core/Src/logic/maze` を使えなくなる(master には残る)．
  - 結果: ビルドはまだしていない(未確認)．
  - 次: ビルド → E0 で符号を確かめる(前進で vl・vr・dist が正，左回りで gyro_z が正) → E1 0.1V を1本取り，seg が 0→1→2→3 と進むことと dropped rows を確かめる．

### 2026-10-28 E2(超信地旋回のステップ)の最初のログと，階段のモード E2S(`feature/system-identification`)

- **E2 の 0.1〜0.5V(227本)では，どの電圧でも超信地旋回は回り続けなかった**．区間1の最初の 0.05 秒で 0.5〜1° 動いて止まり，定常の角速度は 0dps．
  流す方式は 1kHz で行の抜けが全部 0，かけた電圧(pwm × vbat / 4199)は狙いと ±0.5mV 以内，PWM の飽和なし，中止なし．
  - E0r(1.0V まで 0.1V/s で上げる，4本): 1.0V でも回った角度は 6〜10°，角速度は最大 20〜40dps．左の車輪はほぼ動かず(0.5mm 以下)，
    右だけが電圧に比例してじわじわ進んだ(0.1V で約 0.7mm．たわみ・遊びの範囲と推測)．E0 の「0.5mm 動いたら動き出し」の判定はこれに反応してしまう．
  - 計画書の電圧は摩擦なしのモデル(0.5V で約 1820dps)から決めたが，実際は横にこする摩擦に勝つまで回らない．
    以前の調整値(PIVOT_FF_FRIC 0.57〜0.76V + PID)や，左が動きにくい傾向(直進の FRIC_L 0.32 / R 0.16)とも合う．
- **E2S を足した**(ユーザーの案): 1回の手かざしで，0.2〜3.0V を 0.2V 刻みに，電圧ごとに「左回りのステップ → 右回りのステップ」を続ける．
  各ステップは今の E2 と同じ(+V を T_acc(既定 2000ms) → −V で止める → ブレーキ 100ms)で，その後 0.5 秒休んで(区間4)次へ．中止したら残りは捨てる．
  - `logic/sysid/step_test` に段の数・1段の電圧・左右交互を足した(1ステップの E1/E2 は段の数 1)．ログに `step` 列(何番目のステップか．1 始まり)を足して 12 列．
  - 1本で約 90 秒になるので，流すときに先に確保する大きさを 4MB → 8MB にした．
  - 回らない電圧でも 2 秒電流が流れ続けるので，モーター・ドライバの熱に気をつける(どれくらい熱くなるかは未確認)．

  - その後ユーザーの案で，E2S の各ステップは **−V をかけず**「+V を T_acc → 0V(ブレーキ)で止まるまで → 0.5 秒休む」にした(区間2なし)．
    旋回は場所を取らないので −V で早く止める必要がなく，0V にした後の止まり方も「V → 0 のステップ」の応答として使える(立ち上がりと時定数が同じか見られる)．
    止まった = |角速度| < 5dps が 50ms 続いた．2 秒で止まらなければ中止(ABORT(did not stop at 0V)．中止の番号 4)．E1/E2 の1ステップは −V のまま．

    - 区間3の「止まった」に車輪の条件を足した: 機体(|角速度| < 5dps)**かつ**左右の車輪がどちらも 1 カウント/ms 以下，が 50ms 続く
