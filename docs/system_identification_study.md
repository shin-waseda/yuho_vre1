## 1. 言葉の整理

| 言葉 | 意味 | yuho の例 |
|---|---|---|
| **プラント** | 制御される側のもの | モーター + ギア + タイヤ + 機体 |
| **モデル** | プラントの入力と出力の関係を表す式 | 電圧 = FRIC·sign(v) + GAIN·v + ACC·a |
| **パラメータ** | モデルの式の中の定数 | FRIC，GAIN，ACC，スリップの K と C |
| **システム同定** | 入力と出力のデータから，モデル(とくにパラメータ)を決めること | ログから FF の係数を決める |
| **静特性** | 止まっている(定常の)ときの入出力の関係 | 一定の速さで走るのに要る電圧 |
| **動特性** | 変化しているときの関係(遅れ，慣性) | 加速に要る電圧，時定数 |
| **検証** | 決めたモデルが，決めるのに使っていないデータでも合うか確かめること | 演習3 |

モデルの作り方は大きく3つに分けられます．

| 種類 | 作り方 | 長所 | 短所 | yuho の例 |
|---|---|---|---|---|
| **ホワイトボックス** | 物理の法則から式もパラメータも決める | 意味が分かる．データが要らない | 摩擦などはデータシートにない | (2章の計算) |
| **グレーボックス** | 物理から式の形を決め，パラメータはデータで決める | 意味が分かり，実機に合う | 式の形を間違えると合わない | FF の式，スリップのモデル |
| **ブラックボックス** | 式の形も決めず，データに合う式を探す | 物理が分からなくても作れる | パラメータに意味がない | (ARX．演習2) |

yuho のモデルは，ほとんどが**グレーボックス**です．
最初に物理を考えて式の形を決めるのが，同定の一番大事な所です．形が正しければ，パラメータは少ないデータでも決まります．

## 2. 物理からモデルを作る: DC モーター

yuho の FF の式がどこから来るのかを，物理から導きます．

### 2.1 モーターの2つの式

DC モーターは，電気の式と機械の式の2つで表せます．

```
電気:  V = R·i + L·di/dt + Ke·ω_m            (電圧 = 抵抗の電圧降下 + コイル + 逆起電力)
機械:  Kt·i = J·dω_m/dt + b·ω_m + τc·sign(ω_m) + τ_load    (トルク = 慣性 + 粘性摩擦 + クーロン摩擦 + 負荷)
```

| 記号 | 意味 | 単位 |
|---|---|---|
| V | モーターにかける電圧 | V |
| i | 電流 | A |
| ω_m | モーターの軸の角速度 | rad/s |
| R，L | コイルの抵抗，インダクタンス | Ω，H |
| Ke | 逆起電力定数 | V/(rad/s) |
| Kt | トルク定数(SI 単位なら Ke と同じ値) | N·m/A |
| J | 軸から見た慣性モーメント | kg·m² |
| b，τc | 粘性摩擦，クーロン摩擦 | N·m/(rad/s)，N·m |

コイルの遅れ L/R は，小さなモーターではふつう 1ms よりずっと短いので，無視します(L = 0)．
すると電気の式から i = (V − Ke·ω_m)/R になります．

### 2.2 機体につなぐ

yuho の並進(左右が同じに動く)を考えます．

- ギア比 n = 42/13 ≈ 3.23，タイヤの半径 r = 11.9mm なので，機体の速さ v とモーターの角速度の関係は ω_m = (n/r)·v．
- 機体の重さ m は，左右の車輪で半分ずつ受け持ちます(1つの車輪が押す力は m·a/2)．

これを代入して i を消すと，車輪1つあたり次の式になります．

```
V = (R/Kt)·[ J_m·(n/r) + (m/2)·(r/n) ] · a      ← 加速の項  ACC
  + (n/r)·[ Ke + R·b/Kt ]              · v      ← 速さの項  GAIN
  + (R/Kt)·τc                          · sign(v) ← 摩擦の項  FRIC
```

**yuho の FF の式 `電圧 = FRIC·sign(v) + GAIN·v + ACC·a` は，この式そのものです．**
FF の3つの係数には，それぞれ物理の意味があります．

| 係数 | 中身 | 変わる原因 |
|---|---|---|
| FRIC | 摩擦トルク × R/Kt | ギアの噛み合わせ，車軸のねじ(右の FRIC が 0.53 → 0.16V になった) |
| GAIN | 逆起電力 + 粘性摩擦 | モーターの種類，ギア比，タイヤの直径 |
| ACC | モーターの慣性 + 機体の重さ | 機体の重さ(電池を替える，部品を足す) |

時定数は T = ACC/GAIN で，これは「機体の重さまで含めた，モーターの機械的な時定数」です．

### 2.3 自分でやってみる(データシートとの照合)

FAULHABER のデータシートから R，Kt(= Ke)，ロータの慣性 J_m を，機体を量って m を調べて，上の式で ACC と GAIN を計算してみてください．
演習1で求めた値(並進: GAIN 0.000443 V/(mm/s)，ACC 0.000264 V/(mm/s²))と比べます．

- 単位に注意: 上の式は SI(m，kg)で計算し，最後に V/(m/s) → V/(mm/s) にするため 1/1000 を掛けます．
- 合わなければ，どの項が合わないかを考えます(例: GAIN が合わない → 粘性摩擦 b が大きい，ACC が合わない → ギアやタイヤの慣性を忘れている)．
- yuho のモーターの型番はこの文書を書いた時点では確かめていないので，計算はまだしていません．

## 3. モデルの見方: 微分方程式・伝達関数・ステップ応答・離散化

同じモデルをいくつかの形で書けます．どの形でも中身は同じで，目的に合う形を使います．

### 3.1 微分方程式

摩擦を FF で打ち消してあるとすると(u = V − FRIC·sign(v))，

```
ACC·dv/dt + GAIN·v = u     →     T·dv/dt + v = K·u      (K = 1/GAIN，T = ACC/GAIN)
```

これを**1次遅れ系**と言います．

### 3.2 伝達関数

ラプラス変換すると

```
G(s) = V(s)/U(s) = K / (T·s + 1)
```

- K: 定常ゲイン(1V で最後に何 mm/s になるか)
- T: 時定数(どれくらいの速さで落ち着くか)

### 3.3 ステップ応答

電圧を急に u0 だけ上げると，速さは

```
v(t) = K·u0·(1 − e^(−t/T))
```

で増えます．t = T で最後の値の **63%** に届きます．
**ステップ応答を測って 63% の時刻を読めば T が，最後の値を u0 で割れば K が分かります**．これが一番簡単な同定です(8章の実験 A)．

### 3.4 離散化(ログは飛び飛びの時刻の値)

ログは h = 5ms ごとの値なので，時刻 k と k−1 の関係で書くと

```
v[k] = α·v[k−1] + β·u[k−1]        α = e^(−h/T)，β = K·(1 − α)
```

になります(電圧が h の間は一定とした「ゼロ次ホールド」の場合)．
α と β をデータから求めれば，T = −h/ln(α)，K = β/(1 − α) に戻せます．これが演習2の ARX モデルです．

### 3.5 yuho の値(計算)

| | K [mm/s/V] | T [s] |
|---|---|---|
| params.h の FF(左) | 1333 | 0.37 |
| params.h の FF(右) | 2000 | 0.55 |
| 演習1(並進) | 2258 | 0.60 |
| 演習2(ARX，左 / 右) | 1599 / 1910 | 0.42 / 0.47 |

**方法によって値がかなり違います．** 4.3 で理由を考えます．

## 4. データからパラメータを決める: 最小二乗法

### 4.1 考え方

モデルが**パラメータについて1次式**なら，最小二乗法でまとめて決められます．
yuho の FF の式は

```
u = FRIC·sign(v) + GAIN·v + ACC·a  =  [sign(v)  v  a] · [FRIC; GAIN; ACC]
                                       ↑ データから分かる行   ↑ 決めたいパラメータ θ
```

なので，ログの各行を縦に並べると，行列の式 **u ≈ X·θ** になります．
誤差の二乗の和 ‖u − X·θ‖² を一番小さくする θ は

```
θ = (Xᵀ X)⁻¹ Xᵀ u          MATLAB では  θ = X \ u   (1行)
```

です．v や a については1次式でなくても(sign(v) のように)，**θ について1次式**ならこの方法が使えます．

### 4.2 当てはまりの見方

| 指標 | 意味 | 演習での値 |
|---|---|---|
| 残差 RMS | モデルで説明できなかった電圧の大きさ | 0.16〜0.22 V |
| 決定係数 R² | 電圧の変化のうち，モデルで説明できた割合(1 が完全) | 0.58〜0.75 |
| 一致度(fit) | シミュレーションと実測の一致(演習3．100% が完全) | 35〜67% |

R² が高くても，**別のデータでのシミュレーションが合うとは限りません**(4.3)．必ず検証します．

### 4.3 落とし穴(演習で実際に出たもの)

**(1) モデルが成り立たないデータを入れる** — 演習1の `'all'`

探索のログを全部使うと，GAIN が**負**(速いほど電圧が要らない)になりました．
原因は2つありました．

- 尻当てで壁に押し付けている間は，電圧が大きいのに速さはほぼ 0 です．壁の力はモデルにありません．
- スラロームの間は，左右の車輪が機体の回転を通してつながっています．車輪1つのモデルでは表せません．

前進の直線だけにすると，FRIC 0.33V，GAIN 0.00047，ACC 0.00023 と，意味の通る値になりました．
**同定に使うデータは，モデルが成り立つ範囲だけに絞ります**．何を除いたかは必ず書き残します．

**(2) 説明する変数の雑音** — 加速度は速さの微分

加速度 a は速さを微分して作っているので，雑音が大きくなります．
最小二乗法は「X には雑音がない」という前提なので，X に雑音があると，係数が**小さめに出ます**(減衰バイアス)．
演習1の ACC(0.00023)が今の値(0.000275)より小さいのは，この影響かもしれません(確かめていない)．
演習2の ARX は微分を使わないので，この問題が出にくい方法です．

**(3) 閉ループのデータ**

機体は PI で速さを制御しているので，電圧 u は速さ v のずれに応じて変わります．
「入力が出力に左右される」データでは，最小二乗法の答えが偏ることがあります．
それを避ける基本は，**制御を切って(開ループで)決めた電圧を入れる実験**です(8章)．

**(4) 左右のつながり**

左の電圧を「左の加速」と「右の加速」の両方で説明すると，係数がほぼ同じ(0.000131 と 0.000142)になりました(演習1)．
機体の重さを左右で分け合っているので，**左のモーターは右の車輪を加速するのにも電圧を使っています**．
車輪ごとではなく，**並進(左右の平均)と回転(左右の差)に分けてモデルを作る**と，このつながりがなくなります．
実際，並進のモデルは R² が 0.58 → 0.75，検証の一致度が 35〜45% → 67% になりました．

**(5) 区別できないパラメータ(同定可能性)**

スリップの K と C は，今のログでは**別々には決まりません**(演習5)．
誤差の地形を描くと，C が 0〜0.15s の範囲で誤差がほとんど変わらない「平らな谷」になっています．
データに「C の違いで結果が変わる」動きが入っていないためです．
決めるには，C が効く条件(速さを大きく変える，曲がった直後の短い区間を細かく測る)のデータが要ります(8章)．

## 5. yuho の今の決め方を「同定」として読み直す

yuho の FF の決め方は，同定の教科書の言葉で言うと次のようになります．

| yuho のやり方 | 同定の言葉 |
|---|---|
| 2つの速さで定常の電圧を測り，直線で近似した | 静特性の同定(2点の回帰) |
| 加速中と減速中の電圧を平均して，摩擦を打ち消した | 実験を工夫して，邪魔なパラメータを消す |
| 巡航中の I 項が 0 になるように直した | 閉ループでの同定(フィードバックの出力からモデルの誤差を読む) |
| 2つの値で取った I 項から，0 になる値を補間した | 1つのパラメータの探索(割線法) |
| 走った距離の比で直径を直した | 1つのパラメータの最小二乗(1点) |

どれも正しい方法で，少ないログで手早く合わせられました．
ただし，次の限界があります．

- 一度に1つの係数しか見ていないので，**係数どうしの影響**(GAIN を変えると FRIC の最適値も変わる)を見落とします．
- 測ったときの速さ(200〜300mm/s)の外へ外挿しています．演習3では，今の FF は 600mm/s で GAIN が大きすぎる(電圧を多めに出す)ように見えました(7章)．

### 演習4: モデルから PI のゲインを決める(`study4_pi_design`)

```matlab

**IMC(内部モデル制御)による PI の決め方**: 「閉ループを時定数 λ の1次遅れにしたい」と決めると

```
Kp = T / (K·λ)，   Ki = 1 / (K·λ)        (PI の零点 Ki/Kp = 1/T がプラントの極を打ち消す)
```

になります．λ は「どれくらい速く追いかけたいか」で，ほかは全部モデルから決まります．

**結果**(計算): 今のゲイン(Kp 0.015，Ki 0.0376)を IMC として読むと，**λ ≈ 18〜20ms** に当たります(左の FF のモデル)．

位相余裕は 87°，ゲイン余裕は 29 倍で，揺れにくい設定です(1ms の遅れを入れて計算．PWM やギアのがたなど，モデルにない遅れは入っていない)．

**考えてみること**

- λ を 10ms，5ms と小さくすると，ステップ応答と余裕はどう変わるか．
- 実機でステップの行き過ぎが 12% あったのに，モデルでは行き過ぎがほとんどないのはなぜか(モデルにない遅れ，I 項の積分の止め方，FF の誤差)．

```

SLALOM 試験のログ5本で，スリップの K と C を変えたときの誤差(RMS)を地形として描きます．

**結果**(演習): 一番合うのは K 0.027，C 0(RMS 2.27mm)．しかし，誤差が最良 + 0.1mm 以内に入る範囲は **K 0.0185〜0.030，C 0〜0.145s** と広く，谷は C の向きに長く伸びています．

**考えてみること**

- 谷が C の向きに伸びているのはなぜか(このデータでは β がすぐに定常に達し，遅れの影響が出口のずれにほとんど残らない)．
- 谷が曲がっていて，C を大きくすると一番合う K が小さくなる(0.027 → 約 0.02)のはなぜか．
  (考え方の例: 遅れがあると曲がり終わった後も β が残り，出口で横にずれ続ける．その分 K が小さくて済む．確かめてはいない)
- C を決めるには，どんなデータを足せばよいか(8章)．

## 8. 次にやるとよい実験(同定の実験の設計)

同定で一番効くのは，**よいデータを取る実験**です．今のログは「走るための制御」をしながら取ったものなので，同定には向かない所があります．
以下は提案で，ファームの変更が要ります(まだ作っていません)．

### A. 開ループのステップ(静特性と時定数)

- 機体を持ち上げずに床の上で，制御を切って**決めた電圧**(例: 0.5，0.8，1.2，1.6V)を一定時間かけ，速さを記録する．
- 前進と後退の両方．電圧の段ごとに，最後の速さ(静特性 → FRIC と GAIN)と 63% の時刻(時定数 T)を読む．
- 閉ループの偏り(4.3 (3))がなく，微分も要らない．一番まっすぐな方法．
- 注意: 開ループなので向きの制御がなく曲がる．短い距離で止める．壁にぶつからない広い所で行う．

### B. 速さを変えながらの巡航(GAIN の確認)

- 300，600，900，1200mm/s で巡航し，それぞれの I 項を見る(今の制御のままでよい)．
- I 項が速さに比例して負になっていけば，GAIN が大きすぎる(7章の確認)．

### C. 回転のモデル(並進と分ける)

- 超信地旋回を，角速度と角加速度を何通りか変えて行う．
- 「左右の差の電圧」と「角速度・角加速度」で最小二乗をすると，回転の摩擦・速さ・慣性(ヨーの慣性モーメント)が決まる．
- 今の旋回の摩擦 FF(約 100mm/s の1点)が速さによらないのかも分かる．

### D. スリップの C(旋回のモデル)

- SLALOM_SWEEP で，速さを 300〜900mm/s と広く変える．C は速いほど効く．
- 右と左を同じ数ずつ，曲がった直後も両側に壁がある所で．
- 横の壁センサーの mm への換算(傾き)を，同じ日に測っておく(誤差の地形は傾きで変わる)．

### E. PRBS / チャープ(慣れてきたら)

- 巡航の目標の上に，小さなランダムな上げ下げ(PRBS)や，周波数を上げていく正弦波(チャープ)を足す．
- いろいろな速さの変化が1回の走行で入るので，時定数やモデルにない遅れまで見える．divergence_v3 はこの方法で同定していた(`divergens.md`)．
- 道具: この PC の MATLAB には System Identification Toolbox がないので，最小二乗(演習1・2)を自分で組むか，Toolbox を入れる．

## 10. 用語集

| 用語 | 意味 |
|---|---|
| 1次遅れ系 | T·dv/dt + v = K·u で表される系．ステップを入れると指数関数で落ち着く |
| 時定数 T | 1次遅れ系で，ステップ応答が最後の値の 63% に届く時間 |
| 定常ゲイン K | 入力を一定にしたとき，出力が最後に何倍になるか |
| クーロン摩擦 | 速さによらず一定の大きさで，動く向きと逆にかかる摩擦(FRIC) |
| 粘性摩擦 | 速さに比例する摩擦(GAIN の一部) |
| 逆起電力 | モーターが回ると発生する，回転を妨げる向きの電圧(GAIN の主な中身) |
| 最小二乗法 | 誤差の二乗の和が最小になるようにパラメータを決める方法 |
| 決定係数 R² | データのばらつきのうち，モデルで説明できた割合 |
| ARX モデル | 過去の出力と入力の1次式で今の出力を表すモデル(演習2) |
| 1歩先の予測 / シミュレーション | 毎回実測から予測する / モデルの出力だけで進める．検証は後者で行う |
| 開ループ / 閉ループ | 制御なしで入力を決めて入れる / フィードバック制御をしながら |
| PRBS | 0 と 1 がランダムに並ぶ信号．いろいろな周波数を含むので同定の入力に使う |
| IMC | 内部モデル制御．モデルと閉ループの時定数 λ から PI のゲインを計算する方法(演習4) |
| 位相余裕 / ゲイン余裕 | 閉ループが不安定になるまでの余裕．位相余裕は 45〜60° が目安 |
| 同定可能性 | データからパラメータが一意に決まるか(演習5) |
| グレーボックス | 式の形は物理から，パラメータはデータから決めるモデル |
